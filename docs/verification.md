# 真机验收清单

> 当前状态：**未验证**。下列任一项完成后，请在 issue 里附设备与版本信息。

## 环境

| 项 | 值 |
|---|---|
| 眼动源 | EyeTrackVR（记录版本号与追踪算法/标定方式） |
| 显示设备 | 带眼动采集的 HMD / 眼镜（记录型号） |
| 系统 | Windows 10 / 11 x64 |
| 宿主 | FaceGaze Bridge（记录版本号） |

## 步骤

- [ ] EyeTrackVR 设置：OSC 输出地址=本机 IP（同机可 127.0.0.1），端口 9000→8889
- [ ] 输出模式选 VRCFT 参数集（V1 或 V2，分别验一遍）
- [ ] PC 上关闭 VRCFT 及其它占用 8889 的程序
- [ ] FGB「模块库 → 原生模块」安装 `etvr-<版本>.zip`
- [ ] 「模块」页把 EyeTrackVR 设为启动（角色：gaze/eyes），重启引擎
- [ ] 模块卡片显示活跃

## 观察项

- [ ] 向左看 → 注视方向 -X；向右看 → +X（水平极化）
- [ ] 向上看 → +Y；向下 → -Y（垂直极化，尤其注意 V1 双眼共享 Y）
- [ ] 眨眼 → 对应眼 openness 下降，左右眼独立（V2 逐眼；V1 应独立到左右）
- [ ] 睁眼度不拖尾：快速眨眼后 1~2 帧内回到常态（1€ beta=15 应快速跟随）
- [ ] 遮挡摄像头/关闭 ETVR → 10 秒内卡片给出「已 N 秒没有数据」，恢复后回到活跃
- [ ] 表情不受影响（本模块不写形状），头动不改变注视的相对趋势

## 与上游对比（可选但有用）

同一台设备上并用 VRCFT + ETVRTrackingModule，对比同一组注视/眨眼动作的参数曲线。
重点人眼确认：左右极化、±1 对应的实际视角（标定半角）、以及 V1 共享 Y 是否够用。
